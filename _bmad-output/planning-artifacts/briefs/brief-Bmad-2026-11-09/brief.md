# Бриф продукта: «Мур-Гав Маркет»

## Кратко

«Мур-Гав Маркет» — учебный интернет-магазин кормов для кошек и собак с доставкой по Алматы. Покупатель выбирает корм по виду, возрасту и размеру питомца, кладёт товары в корзину и оформляет заказ. Работник магазина ведёт каталог и смотрит заказы в админке.

Проект делается как домашнее задание для практики. Его цель — пройти полный цикл создания веб-магазина: от плана до сайта, который открывается по ссылке в интернете. Образец для вдохновения — [zoomarket.kz](https://www.zoomarket.kz/). Сайт похож на него по устройству, но проще и уже по ассортименту.

## Задача покупателя

Владелец кошки или собаки хочет быстро найти подходящий корм и заказать его домой. В больших зоомагазинах корм теряется среди игрушек, лежанок и наполнителей. Покупателю приходится долго листать каталог, чтобы найти корм для своего питомца, например для котёнка или пожилой крупной собаки.

## Решение

Магазин продаёт только корма и только для кошек и собак. Поэтому каталог короткий и понятный:

- **Два раздела:** «Кошкам» и «Собакам».
- **Фильтры** по возрасту (детёныш, взрослый, пожилой), размеру собаки, типу корма (сухой, влажный, лакомства) и бренду. [ПРЕДПОЛОЖЕНИЕ: это отличие от образца]
- **Цены в тенге**, бесплатная доставка по Алматы от определённой суммы заказа.

## Для кого

- **Покупатель.** Житель Алматы, у которого есть кошка или собака. Хочет заказать корм без поездки в магазин.
- **Администратор магазина.** Добавляет и меняет товары, смотрит новые заказы и меняет их статус.

## Что входит в первую версию

**Для покупателя:**
- Главная страница: шапка с логотипом и меню, баннер с акцией, разделы «Кошкам» и «Собакам», популярные товары и бренды.
- Каталог с фильтрами и карточка товара: фото, описание, состав, вес, цена.
- Корзина: изменение количества, итоговая сумма, условие бесплатной доставки.
- Оформление заказа: имя, телефон, адрес в Алматы, способ оплаты при получении. Настоящей онлайн-оплаты нет.
- Регистрация и вход, личный кабинет с историей заказов.
- Информационные страницы: «Доставка», «Оплата», «О магазине».

**Для администратора:**
- Вход только для администратора.
- Список товаров: добавление, изменение, удаление, загрузка фото.
- Список заказов со сменой статуса: новый, в работе, доставлен, отменён.

## Что не входит

- Настоящая онлайн-оплата картой.
- Товары кроме корма: игрушки, наполнители, аксессуары.
- Животные кроме кошек и собак.
- Блог, отзывы, несколько магазинов-филиалов, мобильное приложение.
- Доставка за пределы Алматы.

## Технологии

Next.js для сайта, Supabase для базы данных, входа пользователей и хранения фото, Vercel для публикации, GitHub для хранения кода. Аккаунты во всех четырёх сервисах уже подключены.

## Как поймём, что получилось

- Сайт открывается по публичной ссылке на Vercel, в том числе с телефона.
- Покупатель может пройти весь путь: найти корм, положить его в корзину, оформить заказ и увидеть заказ в личном кабинете.
- Администратор видит этот заказ в админке и может сменить его статус.
- В каталоге есть хотя бы 20 тестовых товаров для кошек и собак.
- Код лежит в репозитории на GitHub, а документы BMAD сдаются вместе с ним.

## Открытые вопросы

- **Требования преподавателя.** Обязательные страницы, срок сдачи, критерии оценки пока неизвестны.
- **Порог бесплатной доставки.** По умолчанию 12 000 ₸, как в образце. [ПРЕДПОЛОЖЕНИЕ]
- **Внешний вид.** Тёплые оранжево-бежевые цвета по мотивам образца. [ПРЕДПОЛОЖЕНИЕ]
