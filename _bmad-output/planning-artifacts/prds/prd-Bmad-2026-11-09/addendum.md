# Дополнение к PRD: Мур-Гав Маркет

Здесь собраны технические решения и детали, которые не относятся к требованиям, но нужны для архитектуры и разработки.

## Выбранные технологии

Аккаунты во всех сервисах уже подключены (2026-11-09).

- **Next.js** (React) — сайт и админка в одном проекте.
- **Supabase** — база данных Postgres, вход пользователей (email и пароль), хранилище фото товаров.
- **Vercel** — публикация сайта по публичной ссылке.
- **GitHub** — хранение кода.

## Заметки для архитектуры

- Роль администратора — признак в профиле пользователя. Доступ к данным защищается правилами Row Level Security в Supabase, а не только проверкой на странице.
- Создание заказа (FR-11) должно проверять остатки и уменьшать их в одной транзакции, например через функцию базы данных.
- Корзина гостя — в localStorage браузера. Синхронизация корзины между устройствами не требуется.
- Цены хранятся целыми числами в тенге.
- Для «Акций» у товара есть необязательное поле «старая цена».
- Тестовые товары заводятся скриптом начальных данных (seed), не меньше 20 штук.
