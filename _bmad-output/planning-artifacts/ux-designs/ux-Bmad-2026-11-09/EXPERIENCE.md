# Мур-Гав Маркет — как работает сайт

## Foundation

Адаптивный веб-сайт, сначала для телефона, затем для компьютера. Next.js + Tailwind + shadcn/ui. Внешний вид — в `DESIGN.md`, требования и термины — в PRD (термины глоссария PRD используются здесь дословно). Две роли: **Покупатель** (гость или зарегистрированный) и **Администратор**.

## Information Architecture

| Экран | Адрес | Откуда попадают | Зачем | FR |
|---|---|---|---|---|
| Главная | `/` | Логотип, прямой заход | Баннер, плитки «Кошкам»/«Собакам», популярные товары, бренды | FR-1, FR-2 |
| Каталог | `/catalog?animal=&age=&size=&type=&brand=&min=&max=&sort=&page=` | Меню, плитки, бренды, «Акции» | Список товаров с фильтрами и сортировкой | FR-3 — FR-5 |
| Поиск | `/catalog?q=` | Поле поиска в шапке | Тот же каталог с запросом | FR-6 |
| Товар | `/product/[id]` | Карточка товара | Подробности и добавление в корзину | FR-7 |
| Корзина | `/cart` | Значок корзины | Изменение количества, итог, доставка | FR-8, FR-9 |
| Оформление | `/checkout` | Кнопка «Оформить заказ» в корзине | Форма заказа | FR-10, FR-11 |
| Заказ принят | `/order/[id]/success` | После оформления | Подтверждение | FR-12 |
| Вход / Регистрация | `/login`, `/register`, `/reset-password` | «Войти» в шапке | Аккаунт | FR-13 |
| Личный кабинет | `/account` (профиль), `/account/orders`, `/account/orders/[id]` | Аватар в шапке | Профиль и история заказов | FR-14, FR-15 |
| Доставка / Оплата / О магазине | `/delivery`, `/payment`, `/about` | Меню, подвал | Информация | FR-20 |
| Админка: заказы | `/admin/orders`, `/admin/orders/[id]` | `/admin` | Список и статусы заказов | FR-16, FR-19 |
| Админка: товары | `/admin/products`, `/admin/products/new`, `/admin/products/[id]` | Меню админки | Каталог | FR-17 |
| Админка: бренды | `/admin/brands` | Меню админки | Бренды | FR-18 |

«Акции» в меню ведут на `/catalog?sale=1` (товары со старой ценой). Админка имеет своё боковое меню (Заказы, Товары, Бренды, «На сайт») и не показывает шапку магазина.

## Voice and Tone

Дружелюбно, коротко, на «вы», без канцелярита. Лёгкий юмор про питомцев — только в пустых состояниях и подтверждениях.

| Так | Не так |
|---|---|
| «В корзину» | «Добавить товар в корзину покупок» |
| «До бесплатной доставки осталось 2 200 ₸» | «Минимальная сумма для бесплатной доставки не достигнута» |
| «Заказ №1024 принят! Скоро позвоним, чтобы уточнить время» | «Ваш заказ успешно создан» |
| «Ничего не нашли. Попробуйте убрать часть фильтров» | «Результаты отсутствуют» |
| «В корзине пока пусто — питомец ждёт 🐾» | «Корзина пуста» |
| «Введите телефон в формате +7 777 123 45 67» | «Неверный формат» |

## Component Patterns

| Компонент | Где | Поведение |
|---|---|---|
| Карточка товара | Главная, каталог, похожие | Клик по фото или названию — на страницу товара. «В корзину» добавляет 1 шт., показывает Toast «Добавлено в корзину» и обновляет счётчик в шапке. Если товар уже в корзине — кнопка становится счётчиком «− 1 +». |
| Фильтры | Каталог | На компьютере — колонка слева, применяются сразу. На телефоне — кнопка «Фильтры (N)» открывает Sheet снизу с кнопкой «Показать N товаров». Фильтр «Размер» появляется только при животном «Собака». Все фильтры пишутся в адрес страницы. |
| Сортировка | Каталог | Select над сеткой: «Популярные», «Сначала дешёвые», «Сначала дорогие», «Новинки». |
| Счётчик количества | Товар, корзина | Кнопки «−» и «+», минимум 1, максимум — остаток. «−» на 1 в корзине не удаляет: для удаления есть отдельный значок корзины. |
| Плашка доставки | Шапка, корзина | В шапке — общий текст. В корзине — прогресс-полоска к порогу 12 000 ₸ и остаток суммы; при достижении — «Доставка бесплатная 🎉». |
| Форма заказа | Оформление | Поля: имя, телефон (маска +7), адрес, комментарий, способ оплаты (радио: наличные / карта курьеру). Справа (на телефоне — сверху, свёрнуто) — состав и итог. Проверка полей при уходе с поля и при отправке. Кнопка блокируется на время отправки. |
| Таблица админки | Админка | shadcn Table. Заказы — новые сверху, фильтр по статусу вкладками. Статус меняется Select'ом прямо в строке с Toast «Статус обновлён». |
| Форма товара | Админка | Все поля товара из глоссария; «Размер» активен только для собак. Загрузка фото с превью. Удаление — через Dialog подтверждения. |

## State Patterns

| Состояние | Где | Как выглядит |
|---|---|---|
| Загрузка | Каталог, кабинет, админка | Скелетоны карточек/строк по форме будущего содержимого. |
| Пустой каталог по фильтрам | Каталог | «Ничего не нашли. Попробуйте убрать часть фильтров» + кнопка «Сбросить фильтры». |
| Пустая корзина | Корзина | Иллюстрация лапки, «В корзине пока пусто — питомец ждёт 🐾», кнопки «Кошкам» и «Собакам». |
| Нет в наличии | Карточка, товар | Бейдж «Нет в наличии», кнопка неактивна. |
| Нехватка на складе при оформлении | Оформление | Сверху алерт со списком проблемных товаров и доступным количеством; в корзине эти строки подсвечены. Заказ не создан. |
| Ошибка сети | Везде | Toast «Не получилось связаться с сервером. Попробуйте ещё раз». Введённые данные формы сохраняются. |
| Нет доступа | `/admin/*` | Не вошёл — переход на `/login`. Вошёл, но не администратор — страница «Нет доступа» со ссылкой на главную. |
| Пустая история заказов | Кабинет | «Вы ещё ничего не заказывали» + кнопка «В каталог». |
| Страница не найдена | Любой неверный адрес | «Страница убежала за мячиком 🐶» + ссылка на главную. |

## Interaction Primitives

- Мышь и касание. Все действия доступны без наведения (на телефоне наведения нет).
- Кнопки и поля — не меньше 44×44 px для касания.
- Поиск: Enter отправляет запрос; Esc очищает поле.
- Диалоги закрываются по Esc и клику вне окна; открыт максимум один.
- Пагинация страницами, без бесконечной прокрутки.
- После добавления в корзину пользователь остаётся на той же странице.

## Accessibility Floor

- WCAG 2.1 AA для контраста и управления с клавиатуры.
- Порядок Tab совпадает с порядком чтения; видимая рамка фокуса.
- У всех фото товаров есть alt с названием товара; у иконок-кнопок — aria-label («Корзина, 3 товара»).
- Ошибки форм связаны с полями и озвучиваются (aria-describedby, aria-live).
- Язык страницы — `lang="ru"`.

## Responsive & Platform

| Ширина | Поведение |
|---|---|
| < 768px (телефон) | Меню — «гамбургер» в Sheet. Сетка товаров в 2 колонки. Фильтры — Sheet снизу. Итог заказа — свёрнутый блок над формой. |
| 768–1023px (планшет) | Сетка в 3 колонки, фильтры всё ещё в Sheet. |
| ≥ 1024px (компьютер) | Полное меню в шапке. Фильтры колонкой слева, сетка в 4 колонки (3 при открытых фильтрах). |

Проверочная ширина — 375 px без горизонтальной прокрутки (SM-4).

## Inspiration & Anti-patterns

- **Взято у zoomarket.kz:** плашка бесплатной доставки над шапкой, разделы по животным в меню, баннер на главной, блок брендов, тёплые цвета.
- **Не берём:** перегруженное меню из шести животных, блог на главной, длинный SEO-текст, всплывающие окна при входе на сайт.

## Key Flows

### Flow 1 — Айгерим покупает корм для котёнка (UJ-1)
1. Открывает сайт с телефона, видит баннер и плитки. Нажимает «Кошкам».
2. В каталоге нажимает «Фильтры», выбирает «Детёныш» и «Сухой», нажимает «Показать 6 товаров».
3. Открывает карточку, читает состав, нажимает «В корзину» — Toast, счётчик в шапке «1».
4. Возвращается, добавляет влажный корм. Открывает корзину: «До бесплатной доставки осталось 2 200 ₸».
5. Добавляет лакомство из блока «Похожие» — полоска заполнена, «Доставка бесплатная 🎉».
6. «Оформить заказ» → вводит имя, телефон, адрес, выбирает «Наличными».
7. **Кульминация:** «Заказ №1024 принят! Скоро позвоним, чтобы уточнить время» — состав, сумма, адрес.

### Flow 2 — Данияр повторяет заказ (UJ-2)
1. Нажимает «Войти», вводит email и пароль.
2. Аватар → «Мои заказы» → открывает прошлый заказ, видит корм для пожилого лабрадора.
3. Нажимает на название товара в заказе — открывается страница товара. «В корзину».
4. На оформлении имя и телефон уже заполнены, остаётся адрес.
5. **Кульминация:** новый заказ сразу в «Моих заказах» со статусом «Новый».

### Flow 3 — Алия ведёт магазин (UJ-3)
1. Открывает `/admin`, попадает на «Заказы» — вкладка «Новые».
2. Видит заказ Айгерим, открывает, проверяет адрес, ставит «В работе» — Toast «Статус обновлён».
3. Переходит в «Товары» → «Добавить товар», заполняет форму, загружает фото, сохраняет.
4. **Кульминация:** открывает сайт в соседней вкладке — новый корм уже в каталоге.
5. После доставки ставит заказу «Доставлен»; Айгерим увидела бы это в кабинете, если бы была зарегистрирована.
